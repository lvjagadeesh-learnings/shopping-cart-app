# Epic 1 — Frontend development (React.js v19)

> Part of the [Product Stories](../README.md) overview. Epic definition:
> [`../../epics/epic-1-frontend.md`](../../epics/epic-1-frontend.md). Delivery plan:
> [`../../plans/PDLC-1000-frontend/plan.md`](../../plans/PDLC-1000-frontend/plan.md).

Everything a Shopper or Admin sees and interacts with in the browser (React 19 +
TypeScript + Vite SPA).

- **US-1.1**: As a Shopper, I want to browse a grid of products on the homepage, so
  that I can discover what's available.
- **US-1.2**: As a Shopper, I want to view a single product's detail page (name,
  price, description, stock availability), so that I can decide whether to buy it.
- **US-1.3**: As a Shopper, I want to register and log in, and stay logged in across
  page reloads, so that I can save my cart and order history without re-authenticating
  constantly.
- **US-1.4**: As an Admin, I want product management screens (create/edit/remove) that
  are inaccessible to regular Shoppers, so that only authorized users can change the
  catalog.
- **US-1.5**: As a Shopper, I want to add a product to my cart from its detail page or
  the product grid and see a live cart item count/badge in the nav, so that I always
  know what's in my cart.
- **US-1.6**: As a Shopper, I want to update quantities or remove items from my cart,
  so that I can correct mistakes before checking out.
- **US-1.7**: As a Shopper, I want a checkout page and an order confirmation page, so
  that I have confidence my order was placed after completing checkout.
- **US-1.8**: As a Shopper, I want an order history page and an order detail page
  (status, items, totals), so that I can track my purchases.
- **US-1.9**: As an Admin, I want an orders screen where I can advance an order's
  status (e.g. Placed → Processing → Shipped → Delivered), so that fulfillment
  progress is reflected to the customer.
- **US-1.10**: As a Shopper, I want a notifications bell/indicator that shows in-app
  notifications when my order is placed or its status changes, so that I stay
  informed without refreshing the page.
- **US-1.11**: As a Shopper, I want to see "related"/"trending" product
  recommendations on a product's detail page, so that I discover more products.
- **US-1.12**: As a Shopper, I want to leave a rating and written review on a product,
  and see other customers' reviews and the average rating, so that I can share and
  benefit from purchase experiences.
